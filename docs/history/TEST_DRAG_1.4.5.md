# FolderX 1.4.5 拖入验收计划（iOS 17.1.1）

**本版是源码级修复候选，未经 Theos / 真机验证。** 测试前备份旧插件与主屏幕布局，并避免在满屏页测试。

1. 先确认 1×1 小文件夹的原生拖入功能正常。
2. 使用测试页：留出充足空白，仅放一个已成功扩容的 2×2 文件夹和一个无关普通 App。
3. 长按普通 App，拖向 2×2 文件夹中央，观察：拖起前文件夹显示大小、悬停时大小、松手后大小、App 是否进入内部。
4. 确认是否出现原生文件夹打开的动作、是否意外变成 1×1、是否自行恢复到 2×2。
5. 如果拖入没有成功，不要连续重复测试或强制改格，运行随包只读 `folderx_drop_runtime_probe.js`，提供输出 TXT，以确定关键 Hook 是否真实存在。命令：

   ```bash
   frida -U -n SpringBoard -l ~/Downloads/folderx_drop_runtime_probe.js 2>&1 | tee ~/Desktop/folderx_drop_runtime_result.txt
   ```

6. 测试取消拖拽后恢复、不同桌面页和编辑状态；不要在包含重要 App 的满屏页测试。

**指标定义：** 文件夹显示保持放大 ≠ 原生系统认定 2×2 占格；App 真正被模型添加进文件夹才算成功。新增的缓存只在原生拖放回调发生时启用，不能保证系统一定发送此回调。
